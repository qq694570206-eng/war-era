# 可复用声音提示词

先写共同声音风格，例如“温暖、清澈、略带神秘感的手工炼金工坊；近距离、有机材质、避免刺耳高频”。SFX每次改变声源/动作/时序；BGM保持编制/空间一致。下面是模板，不是已执行记录。

## 单次 UI / 动作音

```text
SFX, one single {声源/动作}, for {具体游戏事件}.
{共同风格}。即时起音，{攻击质感}，{尾音长度与形态}。
只出现一次，近距离干净声音，无多次重复，无人声，无音乐，无背景环境。
有效声音约{秒}，末尾留少量自然衰减。
```

例如按钮确认要单次短促，不写“连续闪烁的魔法交响”；脚步明确“一只脚的一次落地”，不能把一整段走路当一步绑定。时间参数留足自然尾音，不靠请求8秒再硬切到0.2秒。

## 环境循环

```text
Sound effect, a continuous steady ambience of {环境声源}.
{共同风格}。稳定密度与空间感，无明显开场/结尾，无突然大事件、音乐或人声。
适合循环播放，末尾与开头保持相同的声场和强度，不淡出至静音。
```

## 循环BGM

```text
Background music / BGM for {场景}，{情绪与共同风格}。
仅器乐：{编制}；约{BPM}，{拍号}，简单稳定的{小节数}小节乐句。
低密度，为对白与提示音留空间。从开头到结尾保持配器、音量与节奏稳定。
无开场铺陈、无结束式、无淡出、无人声或对白，适合游戏连续循环。
```

“seamless”是意图，不是保证。生成后按真实拍点/乐句选循环，不按期望BPM计算后盲裁；识别不到拍点就试听定位或说明限制。

## TTS

prompt只放应念的文本，例如：`欢迎来到工坊。材料已备齐，现在开始调配吧。`
用工具参数选择真实voice_id、emotion、speed。数字/缩写读法不确定时先确定口播文本并保留显示文案映射；不能为方便改变用户台词。没有声音克隆要求时只用工具预设，不模仿具体演员。
