# 《战争纪元 / War Era》— 移动端多背景 RTS 设计案

- 版本：v2（取代 v1）
- 状态：**当前有效**
- 专业域：创意设计
- 作者：创意总监 游有方（本轮团队通道不可用，由制作人代笔）
- 取代：v1（红警架空单背景版，标 **作废**）
- 变更原因：用户明确背景可选——冷兵器 / 一战 / 二战 / 二战后局部战争 / 现代战争，v1 的单背景假设作废

---

## 0. 设计哲学：一个引擎，五个背景

**不是做五个游戏，是做一个 RTS 引擎 + 五个背景包（Theme Pack）。**

| 层 | 内容 | 是否随背景变化 |
|---|---|---|
| **核心机制层**（不变） | 采集→建基地→出兵→交战→摧毁主基地；触屏操作映射；编队/框选/建造流程；克制关系骨架；性能预算 | ❌ 不变 |
| **背景适配层**（随背景包替换） | 资源类型名称、建筑树、单位种类、阵营设定、美术风格、音效音乐、战斗节奏 | ✅ 每包不同 |

### 通用克制骨架（五个背景共享）

无论什么时代，RTS 的战术深度都来自同一套克制循环：

```
  近战/冲锋单位 ←──克制── 远程/射击单位 ←──克制── 重甲/防御单位
        │                    │                      │
      克制                 克制                    克制
        ↓                    ↓                      ↓
  攻城/重火力 ──克制──→ 重甲/防御 ←──克制── 空中/特殊单位
        ↑                                          │
        └──────── 反制特殊 ←──压制──────────────────┘
```

每个背景包只是给这个骨架的每个节点**换皮**：

| 骨架节点 | 冷兵器 | 一战 | 二战 | 二战后局部 | 现代战争 |
|---|---|---|---|---|---|
| 近战/冲锋 | 步兵刀盾 | 刺刀冲锋 | 突击步兵 | 游击队 | 特种部队 |
| 远程/射击 | 弓弩手 | 步枪兵 | 半自动步枪 | 突击步枪 | 精确射手 |
| 重甲/防御 | 重甲骑兵/城墙 | 机枪阵地 | 坦克/碉堡 | 装甲车/地堡 | 主战坦克/防御系统 |
| 攻城/重火力 | 投石机/攻城塔 | 火炮 | 自行火炮 | 火箭炮 | 巡航导弹 |
| 空中/特殊 | —（无） | 气球侦察 | 轰炸机/战斗机 | 武装直升机 | 无人机/电子战 |
| 反制特殊 | 火攻队 | 防空气球 | 防空炮 | 防空导弹 | 反无人机系统 |

> **冷兵器时代没有空中单位**——这是唯一的骨架差异，通过"侦察骑兵/信鸽"替代空中侦察功能。

## 1. 核心玩法循环（通用）

| 阶段 | 玩家行为 | 时长目标 |
|---|---|---|
| ① 侦察 | 派出侦察单位，探明资源点与敌方方位 | 0–60s |
| ② 扩张 | 占资源点，建立采集设施，滚出经济 | 60s–4min |
| ③ 建基地 | 用建造面板放下核心建筑链，形成基地骨架 | 2min–6min |
| ④ 出兵力 | 生产队列出兵，按克制关系配比编队 | 4min–10min |
| ⑤ 交战 | 编队推进，抢占控制点，摧毁敌方关键建筑 | 全程 |
| ⑥ 决胜 | 造出终极武器或滚出经济优势，一波压穿 | 10min–20min |

**节奏随背景微调**：

| 背景 | 单局时长 | 节奏 | 原因 |
|---|---|---|---|
| 冷兵器 | 12–18min | 慢 | 单位移动慢，交锋靠阵型 |
| 一战 | 10–15min | 中慢 | 堑壕战节奏，推进慢 |
| 二战 | 10–15min | 中 | 机械化推进，节奏均衡 |
| 二战后局部 | 8–12min | 中快 | 直升机+特种作战加快 |
| 现代战争 | 8–12min | 快 | 无人机+导弹，决策节奏快 |

## 2. 资源系统（按背景包定义）

### 2.1 通用资源模型

每个背景保持**不超过 3 种资源**——移动端认知负担红线。

| 资源角色 | 定义 | 通用性 |
|---|---|---|
| **主资源** | 造一切东西的基础货币 | 每背景不同名称，但机制相同（采集车/采集队自动往返） |
| **产能资源** | 限制建筑/防御运转的上限 | 类似电力的概念，每背景换皮 |
| **科技点** | 解锁高级单位与终极武器 | 通用机制，通过战斗/控制点积累 |

### 2.2 五个背景的资源定义

| 背景 | 主资源 | 产能资源 | 科技点来源 | 采集方式 |
|---|---|---|---|---|
| 冷兵器 | **粮草** | **人口**（民房提供） | 战功（击杀积累） | 民夫推车往返粮田 |
| 一战 | **军需品** | **煤炭**（煤电厂） | 战功 | 马车/卡车往返仓库 |
| 二战 | **矿石** | **电力**（电厂） | 战功 | 采矿车往返矿点 |
| 二战后局部 | **矿石** | **电力** | 战功 + 控制点 | 卡车往返矿点 |
| 现代战争 | **资金** | **电力** | 情报（控制点+击杀） | 运输车往返资源点 |

> **采集机制统一**：玩家只需指定"挂靠哪个资源点"，采集单位自动往返。这个触屏简化设计五个背景通用。

### 2.3 资源产出曲线（通用）

| 阶段 | 时间窗 | 采集单位数 | 每分钟主资源 | 玩家应达到的状态 |
|---|---|---|---|---|
| 前期 | 0–3min | 1–2 | 300–500/min | 建成核心建筑链 |
| 中期 | 3–8min | 3–5 | 800–1300/min | 多生产线，地图中部开打 |
| 后期 | 8–15min | 5–8 | 1500–2200/min | 出终极武器或高级单位 |

## 3. 基地建设系统（按背景包定义建筑树）

### 3.1 通用建筑树骨架

```
指挥中心 (HQ)               ← 起点，唯一不可重建
├─ 资源建筑                  ← 采集与存储主资源
├─ 产能建筑                  ← 提供产能资源（人口/煤炭/电力）
├─ 步兵生产                  ← 产出基础步兵
│   └─ 特种兵营              ← 需科技点，产出特种单位
├─ 重型生产                  ← 产出载具/骑兵/坦克
│   └─ 高级工厂              ← 需科技点，产出高级载具
├─ 侦察/雷达                 ← 开启全图视野 + 终极武器解锁
│   └─ 终极武器              ← 需雷达 + 科技点
└─ 防御
    ├─ 反步兵防御
    ├─ 反装甲防御
    └─ 高级防御              ← 需科技点
```

## 4. 单位生产系统（通用机制）

### 4.1 生产建筑与队列

| 生产建筑 | 队列上限 | 说明 |
|---|---|---|
| 步兵生产 | 5 | 双建筑可并行加速 |
| 特种兵营 | 3 | 需科技点 |
| 重型生产 | 3 | 主力产能 |
| 高级工厂 | 2 | 需科技点 |

- 队列**自动出兵**，出兵的**集结点**一次设定长期生效。
- 生产中可**取消并退款 70%**。
- **"生产完成从门里开出来"**——这个仪式感五个背景都要有（冷兵器从兵营门口列队走出，现代战争从工厂驶出）。

### 4.2 升级路径（通用四层）

| 层级 | 内容 | 消耗 |
|---|---|---|
| T1 | 基础单位 | — |
| T2 | 装甲/防护强化 | 主资源 ×800 |
| T3 | 火力升级 | 主资源 ×1500 + 科技点 ×3 |
| T4 | 精英单位 + 终极武器解锁 | 主资源 ×2500 + 科技点 ×6 |

## 5. 战斗系统

### 5.1 通用伤害护甲矩阵

| 攻击类型 ↓ / 护甲 → | 轻甲（无甲步兵） | 中甲（轻载具/轻骑） | 重甲（重载具/重骑/碉堡） | 建筑 |
|---|---|---|---|---|
| 轻火力（步枪/弓弩） | **×1.25** | ×0.75 | ×0.4 | ×0.3 |
| 穿甲（炮/穿甲箭/导弹） | ×0.6 | **×1.2** | **×1.15** | ×1.0 |
| 高爆（手雷/投石/火炮） | **×1.4** | ×1.0 | ×0.7 | **×1.3** |
| 特殊（火攻/毒气/电子战） | ×1.0 | **×1.2** | ×1.0 | **×1.1** |
| 对空 | ×0.2 | ×0.2 | ×0.2 | — |

> 冷兵器背景的"穿甲"= 穿甲箭/重弩；"高爆"= 投石/火攻；"特殊"= 火攻/毒烟。矩阵数值通用，只换名称。

### 5.2 战斗规则（通用）

| 规则 | 设计 |
|---|---|
| 命中判定 | 即时命中 + 视觉投射物 |
| 阵型 | 自动保持间距，挤压会被 AOE 惩罚 |
| 攻击优先级 | 先反击攻击自己的人，其次最近 |
| 掩体 | 建筑/地形旁加伤害减免 |
| 自动交战 | 视野内自动开火，可切"坚守" |

### 5.3 终极武器（按背景包定义）

| 背景 | 终极武器 A（阵营 1） | 终极武器 B（阵营 2） | 效果 |
|---|---|---|---|
| 冷兵器 | 火牛阵 | 天火（火箭） | 大范围高爆+持续燃烧 |
| 一战 | 炮击支援 | 毒气弹 | 大范围伤害/范围减速 |
| 二战 | V-2 火箭 | 轰炸机编队 | 大范围高爆 |
| 二战后局部 | 空袭 | 武装直升机群 | 大范围伤害+压制 |
| 现代战争 | 巡航导弹 | 电子战瘫痪 | 大范围伤害/全屏瘫痪 8s |

## 6. 阵营设计（按背景包定义）

每个背景设两个**不对称平衡**的阵营——不是数值抄一遍改改，是底层战术逻辑不同。

### 6.1 冷兵器：苍狼部落 vs 凤凰王朝

| 维度 | 苍狼部落（机动型） | 凤凰王朝（阵地型） |
|---|---|---|
| 哲学 | "以快打慢" | "以厚破锐" |
| 特色 | 骑兵速度 +20%，造价 -10% | 步兵 HP +25%，建筑 HP +30% |
| 弱点 | 正面刚不过，怕拒马 | 机动差，怕被绕后 |
| 主色 | `#4A3B2A`（皮甲褐） | `#8B1E1E`（王朝红） |

### 6.2 一战：协约军 vs 同盟军

| 维度 | 协约军（火力型） | 同盟军（堑壕型） |
|---|---|---|
| 哲学 | "炮火洗地" | "堑壕铁壁" |
| 特色 | 火炮射程 +15%，伤害 +10% | 防御建筑 HP +40%，步兵掩体减免 +15% |
| 弱点 | 推进慢 | 缺乏机动反击能力 |
| 主色 | `#1F4E8C`（协约蓝） | `#4A4A4A`（同盟灰） |

### 6.3 二战：盟军 vs 轴心军

| 维度 | 盟军（机动型） | 轴心军（重装型） |

## 9. 移动端适配设计要点（通用，五背景不变）

### 9.1 触屏操作映射

| 操作 | 触屏方案 |
|---|---|
| 点选单位 | 单击 |
| 框选多选 | 长按后拖动 |
| 移动/攻击 | 选中后单击地面/敌人 |
| 编队 | 长按兵力面板弹出"编入编队"，1–5 号 |
| 集结点 | 建筑选中后"设集结点"再点地面 |
| 镜头平移 | 单指拖动 |
| 缩放 | 双指捏合 0.6x–1.4x |
| 建造 | 左侧面板点选→拖到战场 |

### 9.2 操作红线

- 同时选中单位 ≤ **24**（触屏极限）
- 编队 **5 组**
- 主动操控 = 一组编队，其余自动交战 + 坚守
- 一指一线（不需要三指以上组合手势）
- 所有消耗性操作可撤回（退款 70%）
- 无强制弹窗、无倒计时打断

### 9.3 战斗中禁止旋转屏幕

玩家在设置里选择方向（锁定横屏 / 竖屏 / 自适应），进入战斗后本局内不变。
