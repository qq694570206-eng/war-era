# 移动端 RTS 美术方向与触屏 UI 布局方案

- 版本：v1（首版）
- 状态：**当前有效**
- 专业域：美术 / UI 视觉
- 作者：美术总监 甄塑之（本轮团队通道不可用，由制作人代笔）
- 取代：无（首版）
- 上游依赖：《design-game-design-v1.md》阵营定义与兵种表

## 1. 美术风格定义

### 1.1 风格关键词

**"写实低多边形的冷硬军事风"** —— 不是卡通的胖圆，也不是写实的高模。参考感觉：

> 《钢铁雄心》的厚重感 + 《红警 2》的辨识度 + 现代手游的干净轮廓

三条判定标准（美术评审时用）：
1. **剪影先于细节**：任何单位缩小到 64px 高，看黑 silhouette 能认出是什么兵种。
2. **色块先于贴图**：不靠高精度贴图区分，靠颜色与体块区分。
3. **部件可读**：炮管、履带、枪械必须夸张放大，细碎装饰一律砍掉。

### 1.2 色彩系统

| 用途 | 色值 | 说明 |
|---|---|---|
| 赤卫军主色 | `#8B1E1E` | 深红，比纯红更沉稳 |
| 赤卫军辅色 | `#4A4A4A` | 铁灰，用于金属件 |
| 铁盟主色 | `#1F4E8C` | 藏青 |
| 铁盟辅色 | `#C9D2DC` | 银白，用于高光件 |
| 中立 / 环境 | `#6B6250` | 土黄褐，让双方阵营色都跳得出来 |
| UI 主色（面板） | `#1A1E24` 90% | 近黑半透，可透出战场 |
| UI 强调（可用/选中） | `#F2C14E` | 暖金，同屏唯一饱和色，专用于"你该点这里" |
| 危险 / 不可用 | `#C0392B` | 红，仅用于否定反馈 |
| 友军标识 | `#3FA7D6` | 亮青，和两个阵营色都不撞 |
| 敌军标识 | `#E74C3C` | 朱红 |

**关键原则**：**战场只允许两种高饱和色——阵营色。** UI 的强调色只出现在可交互处。这样玩家的眼睛永远知道"哪里是兵，哪里是按钮"。

### 1.3 低多边形规范（面数预算）

| 对象 | LOD0 | LOD1 | LOD2 | 备注 |
|---|---|---|---|---|
| 步兵 | 2000–2500 | 800 | 200 | 无面部细节，头盔+躯干+枪三段可读 |
| 轻载具 | 3000 | 1200 | 300 | 履带用简单立方，不做链条 |
| 重载具 | 4000 | 1500 | 300 | 炮塔必须独立 mesh（要转向） |
| 飞行器 | 2500 | 1000 | 250 | 螺旋桨用旋转贴图不用 mesh |
| 建筑（小型） | 2000 | 800 | 400 | 兵营、电厂 |
| 建筑（大型） | 5000 | 2000 | 500 | 指挥中心、车厂 |
| 地形装饰 | 250–400 | 80 | — | 石头、树、沙袋 |

**阴影**：不用实时阴影贴图，用**烘焙到地面的圆形/定向暗斑贴花（Blob Shadow）**。这一条能省掉移动端 20%+ 的 GPU。

## 2. 横屏 UI 布局（主态）

> 适配基准：1920×1080 横屏（19.5:9 刘海屏安全区按 2160×1080 处理）

```
┌──────────────────────────────────────────────────────────────────┐
│ ①资源条  💰1250  ⚡18/24  🔬3     ②小地图     ③警报/超武就绪     │
│ ┌─────────┐                                    ┌────────────┐   │
│ │ 💰 1250 │                                    │ ▓▓▓░░░░░  │   │
│ │ ⚡ 18/24 │                                    │  小地图    │   │
│ │ 🔬 3     │                                    │  ▓▓▓░░░   │   │
│ └─────────┘                                    └────────────┘   │
│                                                                  │
│                    ④  战  场  区  域                            │
│                        （全屏铺满）                              │
│                                                                  │
│                                              ┌────────────────┐ │
│                                              │⑤编队栏         │ │
│                                              │ [1][2][3][4][5]│ │
│                                              └────────────────┘ │
│ ⑥建造面板（左下，可收起）                                        │
│ ┌───────────────────────────────────────┐   ┌────────────────┐ │
│ │ [电厂][兵营][车厂][矿场][雷达][塔]    │   │⑦单位信息卡      │ │
│ │ ─────────────────────────────────────  │   │ 犀牛坦克 ×5     │ │
│ │ 生产队列： ■■□□□  坦克 12s            │   │ HP ███████░░   │ │
│ └───────────────────────────────────────┘   │ [攻击][坚守][解散]│ │
│                                              └────────────────┘ │
└──────────────────────────────────────────────────────────────────┘
   ↑ 全屏手势区（单指拖动=平移，双指捏合=缩放）贯穿整个战场区域
```

### 2.1 区域规格

| # | 区域 | 位置 | 尺寸（1080p 基准） | 说明 |
|---|---|---|---|---|
| ① | 资源显示 | 左上角 | 240×110 | 矿石 / 电力 / 科技点，常驻，不遮挡点击 |
| ② | 小地图 | 右上角 | 240×180 | 可点击跳转，可双指放大到全屏 |
| ③ | 警报条 | 右上小地图下方 | 240×48 | 只在有事件时出现（基地被攻击 / 超武就绪） |
| ④ | 战场 | 中央全屏 | 全屏 | **UI 元素全部半透明，不得完全遮挡战场** |
| ⑤ | 编队栏 | 右侧中部 | 80×360 | 竖排 5 个编队按钮，双击编队 = 镜头跳过去 |
| ⑥ | 建造面板 | 左下 | 620×160 | 默认收起成一条 56px 的图标条，点击展开 |
| ⑦ | 单位信息卡 | 右下 | 300×220 | 选中单位时才出现，未选中时隐藏以留出战场 |

### 2.2 布局原则

1. **拇指区优先**：所有高频操作（建造、编队、单位指令）都在**屏幕下半部与右下**——右手拇指的自然覆盖区。
2. **战场是主角**：UI 总遮罩面积 ≤ 屏幕面积的 **28%**。
3. **面板可收起**：建造面板默认半收起状态，释放战场可视面积。
4. **不对称布局**：故意左重右重不同——左边建造（策略）、右边编队与指令（战术），让肌肉记忆分区。

## 3. 竖屏兼容方案

竖屏不是"把横屏旋转一下"，是**重新组织信息层级**。

```
┌──────────────────────┐
│ ①💰1250 ⚡18/24 🔬3  │  ← 顶部单行资源条（58px）
├──────────────────────┤
│                      │
│   ②小地图（缩小）    │  ← 右上角浮动 150×110，
│         ┌──────────┐ │     可缩小为 60×44 图标
│         │▓▓░░░     │ │
│         └──────────┘ │
│                      │
│                      │
│    ③战 场 区（竖向） │
│                      │
│                      │
│              ┌─────┐ │
│              │④编队│ │  ← 右侧竖排迷你编队 44×240
│              │ 1–5 │ │
│              └─────┘ │
├──────────────────────┤
│  ⑤建造面板（横向滚动）│  ← 底部一条 96px 高，
│ [电厂][兵营][车厂][矿]│     手指横向滑动切换
├──────────────────────┤
│ ⑥单位信息 + 指令栏    │  ← 底部 120px，选中单位时展开
│ HP██████░░  [攻][守] │
└──────────────────────┘
```

### 3.1 竖屏适配规则

| 规则 | 说明 |
|---|---|
| **纵向视野压缩** | 竖屏可见战场宽度只有横屏的 55%，因此**摄像机 zoom 基准要下移**：竖屏 `orthographicSize` 比横屏大 35%，让单位不至于过小 |
| **战场纵向更长** | 竖屏的天然优势是纵向空间。UI 布局应该引导玩家**纵向推进**（上下路），而不是横向 |
| **建造面板转横向滚动** | 竖屏底部宽度只够放 4 个图标，用横向滚动条切换分类（建筑 / 防御 / 单位） |
| **单位信息卡下沉合并** | 竖屏的编队栏与信息卡合并为底部一条，节省 220px |
| **手势一致** | 单指平移 / 双指缩放 / 长按框选**横竖屏完全一致**，绝不因为竖屏改变手势 |
| **小地图可折叠** | 竖屏小地图挡战场，必须支持缩成 60×44 的图标，点击展开 |

### 3.2 横竖屏切换的技术处理

- **不在游戏中强制切换**（切换导致摄像机与 UI 重排，战斗中体验灾难）。
- 玩家在**设置里选择方向**（锁定横屏 / 锁定竖屏 / 自适应），选择后本局内不变。
- 主菜单与基地界面可自由旋转，进入战斗前锁定。

> 这是移动 RTS 的一条经验：**战斗中途旋转屏幕必须禁止**。玩家拇指位置一换，操作全乱。

## 4. 触屏交互视觉反馈

| 交互 | 视觉表现 | 时长 |
|---|---|---|
| **单击选中** | 脚下出现阵营色圆环（友军青 / 敌军红）+ 轻微缩放 1.05 | 0.15s 淡入 |
| **框选** | 半透明阵营色矩形框 + 内部单位逐一亮起 | 拖动实时 |
| **多选完成** | 所有单位统一圆环 + 屏幕中央短暂数字提示"选择 12 个单位" | 0.6s 淡出 |
| **移动命令** | 目标点出现绿色圆环扩散 + 单位朝方向亮一下 | 0.5s |
| **攻击命令** | 目标上出现红色准星 + 一圈十字刻度 | 常驻至开火 |
| **建筑放置** | 半透明预览模型，**绿框=可建 / 红框=不可建**（含原因提示"离建筑太近"） | 拖动实时 |
| **建造进度** | 建筑从下往上"生长"，配灰尘粒子 | 建造时长 |
| **不可点击** | 图标签灰 + 下方红色小字提示缺失条件（如"缺 200 矿石"） | 常驻 |
| **手势提示** | 首关教学用半透明手指动画引导 | 首次出现 |

## 5. 单位辨识度设计（手机小屏幕的关键）

在 6 寸屏上，一个单位可能只有 40×40 像素。怎么让玩家分辨？

| 手段 | 做法 | 优先级 |
|---|---|---|
| **① 底座标识环** | 每个单位脚下有阵营色环，**环的粗细表示单位等级**（1px/2px/3px） | ★★★★★ 最重要 |
| **② 剪影差异化** | 步兵=人形细高；载具=扁宽+履带；飞行=悬停+阴影脱离 | ★★★★★ |
| **③ 轮廓描边** | 单位外描 1px 深色边——低多边形+描边在任意背景上都清晰 | ★★★★☆ |
| **④ 武器外露** | 炮管长度/口径直接对应伤害档次（越长越粗=越强） | ★★★★☆ |
| **⑤ 分类图标** | 单位血条上方小图标（盾=重甲，箭头=机动，星=精英） | ★★★☆☆ |
| **⑥ 队伍色点缀** | 单位肩部/车顶小色块，避免全屏混战看不清归属 | ★★★☆☆ |
| **⑦ 动态标识** | 开火时枪口闪光，不同武器不同颜色（子弹=黄，能量=蓝）——**战场上最有效的辨识线索** | ★★★★☆ |

**反面设计（禁止）**：
- ❌ 只在模型上涂颜色区分阵营（混战中看不清）。
- ❌ 用血条颜色区分（血条颜色表示血量，会冲突）。
- ❌ 单位尺寸差异过大（小单位在手机上不可见）。

## 7. 阶段 2 最小清单（Demo 阶段替代方案）

| 项目 | 阶段2 用什么代替 | 阶段3 换成什么 |
|---|---|---|
| 步兵模型 | 胶囊体 + 方头 | 低多边形步兵（2500 面） |
| 载具模型 | 立方体 + 圆柱炮管 | 低多边形载具（4000 面） |
| 建筑 | 不同颜色的方块 + 文字标注 | 完整建筑模型 |
| 地形 | 一张纯色平面 + 网格线 | 带 Splat 的地形 mesh |
| 单位标识环 | Unity 内置 Plane + 纯色材质 | 带光效的环形贴图 |
| UI 图标 | 纯色圆角矩形 + 文字 | 手绘图标 |
| 特效 | 用一个粒子爆点代替所有特效 | 分类特效（见特效方案） |
| 音效 | 静音或用占位音 | 完整音效 |

**验收点（阶段2 必须可读）**：
1. 在手机实际屏幕上，**能一眼分清步兵 / 载具 / 建筑**三类。
2. 框选 10 个单位时，**单位没有重叠成一坨**。
3. 建筑放置预览的**绿框红框**在战场背景下清晰可辨（不能和地形混色）。
