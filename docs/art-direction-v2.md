# 移动端多背景 RTS 美术方向与触屏 UI 布局方案

- 版本：v2（取代 v1）
- 状态：**当前有效**
- 专业域：美术 / UI 视觉
- 作者：美术总监 甄塑之（本轮团队通道不可用，由制作人代笔）
- 取代：v1（红警单背景版，标 **作废**）
- 变更原因：用户明确背景可选——冷兵器/一战/二战/二战后局部/现代战争，v1 的单一美术风格作废

## 1. 五背景美术风格定义

### 1.1 各背景风格关键词

| 背景 | 风格关键词 | 参考感觉 | 色调 |
|---|---|---|---|
| 冷兵器 | 木质粗粝、皮甲质感、土色大地 | 《全面战争》古代版 + 国风水墨剪影 | 土黄+暗红+皮褐 |
| 一战 | 灰绿军装、泥泞战壕、铁丝锈迹 | 《战地 1》低多边形版 | 灰绿+泥褐+锈红 |
| 二战 | 卡其迷彩、钢铁质感、混凝土 | 《红警 2》低多边形版 | 卡其+铁灰+军绿 |
| 二战后局部 | 沙漠迷彩、预制板、铁皮 | 《冲突世界》中东版 | 沙黄+橄榄绿+铁灰 |
| 现代战争 | 碳纤维、数码迷彩、模块化 | 《使命召唤》低多边形版 | 数码迷彩+哑光黑+青 |

### 1.2 通用美术判定标准（五背景共享）

1. **剪影先于细节**：任何单位缩小到 64px 高，看黑 silhouette 能认出是什么兵种。
2. **色块先于贴图**：不靠高精度贴图区分，靠颜色与体块区分。
3. **部件可读**：武器/盾牌/炮管必须夸张放大，细碎装饰砍掉。

### 1.3 阵营主色系统

| 背景 | 阵营 1 主色 | 阵营 2 主色 | 中立环境色 | 友军标识 | 敌军标识 |
|---|---|---|---|---|---|
| 冷兵器 | `#8B1E1E`（王朝红/苍狼褐 `#4A3B2A`） | 对应 | `#6B6250`（土黄） | `#3FA7D6` | `#E74C3C` |
| 一战 | `#1F4E8C`（协约蓝） | `#4A4A4A`（同盟灰） | `#5F5A4A`（泥褐） | 同上 | 同上 |
| 二战 | `#1F4E8C`（盟军藏青） | `#5C5C5C`（轴心铁灰） | `#6B6250` | 同上 | 同上 |
| 二战后局部 | `#2B4C7E`（蓝水蓝） | `#8B7355`（沙暴黄） | `#C4A96A`（沙漠） | 同上 | 同上 |
| 现代战争 | `#0D7377`（量子青） | `#6B2C5C`（铁幕紫） | `#4A4A4A`（城市灰） | 同上 | 同上 |

> **友军/敌军标识色五背景统一**——`#3FA7D6`（友）与 `#E74C3C`（敌）。玩家切换背景包时，阵营色变了但友敌标识不变，避免认知混乱。

### 1.4 UI 主色（五背景共享）

| 用途 | 色值 | 说明 |
|---|---|---|
| UI 面板底色 | `#1A1E24` 90% | 近黑半透，五背景通用 |
| UI 强调（可交互） | `#F2C14E` | 暖金，同屏唯一饱和色 |
| 危险/不可用 | `#C0392B` | 红 |

### 1.5 低多边形面数预算（五背景统一）

| 对象 | LOD0 | LOD1 | LOD2 |
|---|---|---|---|
| 步兵 | 2000–2500 | 800 | 200 |
| 骑兵/轻载具 | 3000 | 1200 | 300 |
| 重骑兵/重载具 | 4000 | 1500 | 300 |
| 飞行器 | 2500 | 1000 | 250 |
| 小型建筑 | 2000 | 800 | 400 |
| 大型建筑 | 5000 | 2000 | 500 |
| 地形装饰 | 250–400 | 80 | — |

**阴影**：五背景统一用**烘焙地面暗斑（Blob Shadow）**，不用实时阴影——省 20%+ GPU。

## 2. 横屏 UI 布局（五背景通用）

> UI 布局骨架五背景完全相同，只是图标与面板风格换皮。

```
┌──────────────────────────────────────────────────────────────────┐
│ ①资源条  [主资源] [产能] [科技]    ②小地图     ③警报/终极武器    │
│ ┌─────────┐                         ┌────────────┐             │
│ │ 主资源   │                         │  小地图     │             │
│ │ 产能     │                         │             │             │
│ │ 科技     │                         └────────────┘             │
│ └─────────┘                                                     │
│                    ④  战  场  区  域                            │
│                        （全屏铺满）                              │
│                                              ┌────────────────┐ │
│                                              │⑤编队栏         │ │
│                                              │ [1][2][3][4][5]│ │
│                                              └────────────────┘ │
│ ⑥建造面板（左下，可收起）                                        │
│ ┌───────────────────────────────────────┐   ┌────────────────┐ │
│ │ [建筑图标网格]                        │   │⑦单位信息卡      │ │
│ │ 生产队列： ■■□□□                     │   │ HP ███████░░   │ │
│ └───────────────────────────────────────┘   │ [攻击][坚守][解散]│ │
│                                              └────────────────┘ │
└──────────────────────────────────────────────────────────────────┘
```

### 2.1 建造面板的背景换皮

| 背景 | 建造面板风格 | 图标风格 |
|---|---|---|
| 冷兵器 | 木牌+绳挂 | 毛笔字+线描图腾 |
| 一战 | 钢板铆钉 | 军用地图标注风 |
| 二战 | 战术终端 | 军用图标+编号 |
| 二战后局部 | 野战折叠板 | 沙盘标注风 |
| 现代战争 | 触控平板 UI | 扁平化数字图标 |

### 2.2 区域规格（五背景统一）

| # | 区域 | 位置 | 尺寸（1080p） | 说明 |
|---|---|---|---|---|
| ① | 资源条 | 左上 | 240×110 | 主资源/产能/科技 |
| ② | 小地图 | 右上 | 240×180 | 可点击跳转 |
| ③ | 警报 | 右上小地图下 | 240×48 | 事件才出现 |
| ④ | 战场 | 中央 | 全屏 | UI 总遮罩 ≤ 28% |
| ⑤ | 编队栏 | 右中 | 80×360 | 竖排 5 组 |
| ⑥ | 建造面板 | 左下 | 620×160 | 默认半收起 |
| ⑦ | 单位信息 | 右下 | 300×220 | 选中时出现 |

### 2.3 布局原则（不变）

1. 拇指区优先：高频操作在屏幕下半部右下。
2. 战场是主角：UI 总遮罩 ≤ 28%。
3. 面板可收起。
4. 不对称布局：左策略、右战术。

## 3. 竖屏兼容方案（五背景通用）

```
┌──────────────────────┐
│ ①[主资源] [产能] [科技]│  ← 顶部单行资源条
├──────────────────────┤
│   ②小地图（可折叠）   │
│                      │
│    ③战 场 区（竖向） │
│                      │
│              ┌─────┐ │
│              │④编队│ │
│              └─────┘ │
├──────────────────────┤
│  ⑤建造面板（横向滚动）│
├──────────────────────┤
│  ⑥单位信息 + 指令栏    │
└──────────────────────┘
```

竖屏适配规则不变（见 v1），核心：
- 摄像机 zoom 基准下移，单位不至于过小
- 建造面板转横向滚动
- 战斗中禁止旋转屏幕

## 4. 触屏交互视觉反馈（五背景共享，换皮差异标注）

| 交互 | 通用视觉 | 背景换皮差异 |
|---|---|---|
| 选中圆环 | 脚下阵营色环 | 冷兵器=木圈；一战/二战=油漆圈；现代=全息环 |
| 框选框 | 半透明矩形 | 冷兵器=毛笔框；现代=数字框 |
| 移动指示 | 目标点扩散环 | 冷兵器=旗帜标记；现代=数字靶标 |
| 攻击准星 | 红色十字 | 冷兵器=箭头；现代=十字准星 |
| 建筑放置 | 绿框/红框 | 五背景统一（最不能改的——辨识度优先于风格） |
| 伤害飘字 | 数字上飘 | 冷兵器=毛笔字；现代=数字字体 |

> **建筑放置的绿框/红框五背景不换皮**——辨识度 > 风格统一。玩家在任何背景都要一眼看出"能不能建"。

## 5. 单位辨识度设计（五背景通用策略）

| 手段 | 做法 | 优先级 |
|---|---|---|
| ① 底座标识环 | 阵营色环，粗细=等级 | ★★★★★ |
| ② 剪影差异化 | 步兵=细高；骑兵/载具=扁宽；飞行=悬空 | ★★★★★ |
| ③ 轮廓描边 | 1px 深色边 | ★★★★☆ |
| ④ 武器外露 | 武器长度/口径对应伤害档次 | ★★★★☆ |
| ⑤ 分类图标 | 血条上方小图标 | ★★★☆☆ |
| ⑥ 队伍色点缀 | 肩部/顶部件色块 | ★★★☆☆ |
| ⑦ 开火闪光 | 不同武器不同色（子弹=黄，能量=蓝，火攻=橙红） | ★★★★☆ |

### 各背景的剪影差异化要点

| 背景 | 步兵剪影 | 骑兵/载具剪影 | 攻城/重武器剪影 |
|---|---|---|---|
| 冷兵器 | 人形+盾/弓 | 马+骑手轮廓 | 大型木架/投臂 |
| 一战 | 人形+步枪 | 早期坦克菱形 | 长炮管炮架 |
| 二战 | 人形+钢盔 | 坦克方形+炮塔 | 自行火炮长管 |
| 二战后局部 | 人形+头盔 | 装甲车方形 | 火箭炮多管 |
| 现代战争 | 人形+战术背心 | 坦克低矮楔形 | 无人机十字形 |

## 6. UI 素材预算（五背景共享基础设施）

| 资产 | 尺寸 | 数量 | 说明 |
|---|---|---|---|
| UI 主框架图集 | 2048×2048 | 1 张（五背景共享） | 按钮/面板/通用元素 |
| 背景专属图标图集 | 1024×1024 | **每背景 1 张**（5 张） | 建筑图标/单位头像 |
| 小地图遮罩 | 512×512 | 1 张 | 迷雾用 |
| 血条/圆环 | 256×256 | 1 张 | |
| 字体 | — | 2 套 | 中英文 SDF |

**总 UI 内存**：框架共享约 32MB + 每背景图标约 8MB = 当前加载的背景包总计约 40MB（不会同时加载五个背景）。

## 7. 资源管理策略（多背景包）

| 策略 | 说明 |
|---|---|
| **背景包按需加载** | 玩家选择背景后，用 Addressables 加载该背景的美术/音效资源包 |
| **通用框架常驻** | UI 框架/血条/选中环等五背景共享资源启动时常驻 |
| **背景包互斥** | 同一时间只加载一个背景包，切换时释放上一个 |
| **每个背景包约 200–300MB** | 含该背景的全部单位/建筑/地形/音效 |

## 8. 阶段 2 最小清单（五背景统一策略）

| 项目 | 阶段2 用什么代替 | 阶段3 换成什么 |
|---|---|---|
| 步兵模型 | 胶囊体+方头 | 该背景低多边形步兵 |
| 载具/骑兵 | 立方体/圆柱 | 该背景载具/骑兵模型 |
| 建筑 | 不同色方块+文字 | 该背景建筑模型 |
| 地形 | 纯色平面+网格 | 该背景地形（草地/泥地/沙漠/城市） |
| 单位标识环 | 纯色圆环 | 带光效环形贴图 |
| UI 图标 | 纯色圆角矩形+文字 | 该背景风格手绘图标 |
| 特效 | 1 个通用爆点 | 分类特效 |
| 音效 | 静音或占位 | 该背景音效 |

**阶段 2 验收点（不变）**：
1. 手机屏幕上能一眼分清步兵/载具/建筑三类。
2. 框选 10 个单位不重叠成一坨。
3. 建筑放置绿框红框在战场背景下清晰可辨。

> **建议阶段 2 只做一个背景的 Demo**（推荐二战——单位种类最丰富、视觉辨识度最高），验证核心机制后再扩展其他背景包。
