## 1. 世界观框架

### 1.1 五个背景的世界设定

每个背景包不只是换皮——它是一个**完整的战争世界**，有自己的地理、阵营对立逻辑、战场环境。

| 背景 | 世界设定 | 阵营对立逻辑 | 战场地理 |
|---|---|---|---|
| 冷兵器 | 古代大陆，草原部落南下入侵农耕王朝 | 游牧 vs 农耕 | 草原/关隘/城池/河流 |
| 一战 | 1914-1918 欧洲大陆，堑壕战绞肉机 | 协约 vs 同盟 | 战壕/弹坑/铁丝网/焦土 |
| 二战 | 1939-1945 全球战场，机械化闪电战 | 盟军 vs 轴心 | 平原/城市废墟/海滩/雪地 |
| 二战后局部 | 冷热交替的第三世界代理人战争 | 蓝水旅(政府军) vs 沙暴军(游击队) | 沙漠/丛林/贫民窟/山路 |
| 现代战争 | 近未来信息战，无人机与电子战 | 量子联盟(高科技) vs 铁幕阵线(重装) | 城市/工业区/电子战场 |

### 1.2 每背景的地图数量

| 类型 | 数量/背景 | 说明 |
|---|---|---|
| 遭遇战地图 | 6 张 | 1v1 / 2v2 / 4 人混战各 2 张 |
| 战役关卡 | 15 关 | 4 章 × 3-4 关 |
| 总计 | 21 张/背景 | 5 背景共 105 张 |

## 2. 地图结构设计

### 2.1 地图尺寸

| 地图类型 | 世界尺寸（像素） | 格子数 | 说明 |
|---|---|---|---|
| 1v1 小图 | 1600×1000 | 80×50 | 快速对局 8-12 分钟 |
| 2v2 中图 | 2400×1600 | 120×80 | 标准 10-15 分钟 |
| 4 人大图 | 3200×2000 | 160×100 | 长局 15-20 分钟 |

> 格子大小 = 20 像素。单位碰撞半径 8-17 像素。摄像机视野约 800×600 像素。

### 2.2 地图元素构成

每张地图由以下元素组成：

```
地图 = 地形底图 + 矿点 + 障碍物 + 控制点 + 出生点 + 装饰物
```

| 元素 | 说明 | 数据结构 |
|---|---|---|
| **地形底图** | 草地/沙漠/城市/雪地等基底纹理 | Tilemap 或单张大图 |
| **矿点** | 可采集的资源点（3-6 个/图） | OreNode 列表 |
| **障碍物** | 阻挡通行与建造的地形（建筑废墟/岩石/树林/铁丝网） | Collider2D 列表 |
| **控制点** | 可占领的战略点（给科技点/视野/经济加成） | ControlPoint 列表 |
| **出生点** | 玩家与敌方的初始 HQ 位置 | Vector3 列表 |
| **装饰物** | 纯视觉不影响玩法（树/草/废墟碎片/路面） | Sprite 列表 |

### 2.3 地图数据格式（ScriptableObject）

```csharp
[CreateAssetMenu(fileName = "MapDef_", menuName = "IronFrontline/Map Definition")]
public class MapDefinition : ScriptableObject
{
    public string mapId;
    public string displayName;
    public string themeId;          // ancient/ww1/ww2/postwar/modern
    public int playerCount;         // 1v1=2, 2v2=4, 4人=4
    public Vector2 worldSize;       // 世界尺寸
    public Sprite terrainSprite;    // 地形底图
    public Vector3[] playerStartPositions; // 各玩家出生点
    public OreNodeData[] oreNodes;  // 矿点
    public ObstacleData[] obstacles;// 障碍物
    public ControlPointData[] controlPoints; // 控制点
    public DecorationData[] decorations; // 装饰物
}
```

## 4. 地形系统设计

### 4.1 地形类型

| 地形类型 | 所属背景 | 视觉 | 通行 | 建造 | 特殊效果 |
|---|---|---|---|---|---|
| 草地 | 冷兵器/二战 | 绿色草地纹理 | ✅ | ✅ | — |
| 沙漠 | 二战后局部 | 黄沙纹理 | ✅ | ✅ | — |
| 城市路面 | 一战/二战/现代 | 灰色柏油路 | ✅ | ✅ | — |
| 雪地 | 二战(东线) | 白色雪地 | ✅ | ✅ | 移动速度 -10% |
| 泥地 | 一战 | 棕色泥泞 | ✅ | ✅ | 移动速度 -15% |
| 河流 | 通用 | 蓝色水面 | ❌ | ❌ | 不可通行（桥可过） |
| 高地 | 通用 | 地势抬高 | ✅ | ✅ | 视野 +50% |
| 森林 | 冷兵器/二战后 | 绿色树丛 | ✅ | ❌ | 隐蔽（被发现距离 -50%） |
| 建筑废墟 | 一战/二战/现代 | 灰色碎石 | ❌ | ❌ | 不可通行+掩体（附近+20%减免） |
| 铁丝网 | 一战 | 锋利铁丝 | ❌ | ❌ | 不可通行+步兵经过掉血 |
| 战壕 | 一战 | 深沟 | ✅(仅步兵) | ❌ | 步兵入壕+30%减免，载具不能进 |

### 4.2 地形渲染方案

**方案：Tilemap + 自定义 Rule Tile**

| 层 | 用途 | 实现 |
|---|---|---|
| 地形层 | 草地/沙漠/路面等底纹 | Unity Tilemap + Rule Tile |
| 障碍层 | 建筑/岩石/铁丝网等 | Tilemap 或独立 Sprite + Collider2D |
| 装饰层 | 树/草/碎片等纯视觉 | SpriteRenderer 散布 |
| 道路层 | 路面标记线 | Tilemap 覆盖在地形上 |

### 4.3 地形对玩法的影响

| 地形 | 影响的实现方式 |
|---|---|
| 移动速度变化 | FlowFieldPathfinding 的格子 cost 加成（泥地 cost ×1.15） |
| 视野变化 | FogOfWarSystem 检查单位所在格子是否高地 |
| 隐蔽效果 | 森林格子的敌方发现距离 ×0.5 |
| 掩体减免 | 战斗结算时检查目标附近是否有废墟格子 |
| 不可通行 | FlowFieldPathfinding 标记为 blocked |

## 5. 控制点系统

### 5.1 控制点定义

控制点是地图上的**战略争夺点**——占领后给持续加成。

| 控制点类型 | 加成 | 占领方式 | 视觉 |
|---|---|---|---|
| 经济点 | 每秒 +20 矿石 | 友军单位停留 10 秒 | 金色旗帜 |
| 科技点 | 每秒 +1 科技点 | 同上 | 紫色旗帜 |
| 视野点 | 周围 300px 全图可见 | 同上 | 蓝色信标 |
| 高地点 | 周围视野 +50% | 同上 | 山顶烽火 |

### 5.2 控制点数据

```csharp
public class ControlPoint : MonoBehaviour
{
    public ControlPointType type;
    public float captureTime = 10f;
    public float captureProgress = 0f;
    public int controllingPlayer = -1; // -1=中立, 0=玩家, 1=敌方
    public float radius = 40f;
}
```

### 7.2 MapLoader（地图加载器）

新增脚本——负责根据 MapDefinition 加载地图：

```csharp
public class MapLoader : MonoBehaviour
{
    public MapDefinition[] availableMaps;

    public void LoadMap(string mapId)
    {
        MapDefinition map = FindMap(mapId);
        if (map == null) return;

        // 1. 加载地形
        LoadTerrain(map);

        // 2. 生成矿点
        foreach (var ore in map.oreNodes)
            SpawnOreNode(ore);

        // 3. 生成障碍物
        foreach (var obs in map.obstacles)
            SpawnObstacle(obs);

        // 4. 生成控制点
        foreach (var cp in map.controlPoints)
            SpawnControlPoint(cp);

        // 5. 生成装饰物
        foreach (var dec in map.decorations)
            SpawnDecoration(dec);

        // 6. 设置出生点
        SetupSpawnPoints(map.playerStartPositions);

        // 7. 重新生成流场网格
        FlowFieldPathfinding.Instance.GenerateFlowField(
            map.playerStartPositions[0]);
    }
}
```

| 迷雾 | 黑色/半透明覆盖 | 未探索=黑，已探索=半暗 |
| 摄像机框 | 金色矩形 | 当前视野范围 |

### 9.2 小地图交互

- **点击跳转**：点击小地图→摄像机移动到对应位置
- **缩放显示**：双指捏合小地图可放大查看细节
- **折叠**：竖屏模式下可折叠为图标

## 10. 场景过渡

### 10.1 场景流

```
主菜单场景 (MainMenu.unity)
  → 选择背景/阵营/难度/地图
  → 加载条
  → 战斗场景 (Battle.unity)
    → MapLoader 加载选定地图
    → GameManager 初始化双方基地
    → 游戏进行
    → 胜负判定
  → 结算画面
  → 返回主菜单 或 再来一局
```

### 10.2 场景间数据传递

用 `PlayerPrefs` 或静态变量传递选择：

```csharp
// 主菜单存选择
PlayerPrefs.SetString("SelectedFaction", "allies");
PlayerPrefs.SetString("SelectedDifficulty", "normal");
PlayerPrefs.SetString("SelectedMap", "plain");
PlayerPrefs.SetString("SelectedTheme", "ww2");

// Battle 场景读选择
string faction = PlayerPrefs.GetString("SelectedFaction", "allies");
```

## 11. 首批需要制作的地图资产清单（阶段 B）

阶段 B（方块占位）只需要地图的**数据定义**，不需要美术资产：

|---|---|---|---|
