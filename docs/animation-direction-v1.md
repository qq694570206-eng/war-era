## 1. 单位动画状态机

### 1.1 步兵（含特种兵、狙击手）

| 状态 | 时长 | 循环 | 转换条件 | 备注 |
|---|---|---|---|---|
| Idle | 4s | 循环 | 无输入 | 必须带轻微呼吸起伏，否则像标本 |
| Move | 1.0s | 循环 | 收到移动命令 | 步频与移动速度强关联 |
| Attack | 0.8s | 单次 | 进入射程且目标有效 | 上半身开火，下半身可站定 |
| Move+Attack | 1.2s | 循环 | 移动中开火 | 简化版，腿部走、手臂抬枪 |
| HitReact | 0.3s | 单次 | 受击（30% 概率触发，防抖动） | 不要每次受击都播，会像卡帧 |
| Death | 0.9s | 单次 | HP ≤ 0 | 见 §4 死亡动画 |
| DeathByExplosion | 1.2s | 单次 | 被高爆/超武击杀 | 击飞弧线，比普通死亡更夸张 |

### 1.2 载具（含坦克、采矿车）

| 状态 | 时长 | 循环 | 转换条件 | 备注 |
|---|---|---|---|---|
| Idle | 3s | 循环 | — | 引擎轻微震动 |
| Move | 1.0s | 循环 | 移动命令 | 履带滚动 = UV 滚动，不做骨骼 |
| TurretIdle | 3s | 循环 | 炮塔无目标 | 炮塔独立层，可叠加在车身动画上 |
| TurretRotate | 0.5s | 单次 | 目标偏离炮口 > 15° | **炮塔转向必须独立动画层** |
| Attack | 0.6s + 后坐 | 单次 | 开火 | 炮管后坐 0.15m 回弹，节奏感来源 |
| HitReact | 0.2s | 单次 | 受击（护甲越高越少触发） | 只有金属抖动，不位移 |
| Destroyed | 1.5s | 单次 | HP ≤ 0 | 炮塔飞脱 + 车体下沉，保留残骸 |

### 1.3 飞行器

| 状态 | 时长 | 循环 | 备注 |
|---|---|---|---|
| Hover | 2s | 循环 | 上下浮动 0.15m，必须不规律（两段不同相位） |
| Move | 1s | 循环 | 机身俯仰随速度变化 |
| Attack | 0.7s | 单次 | 机头微微下压 |
| Crash | 2s | 单次 | 冒烟螺旋下坠 + 落地爆炸，轨迹不可预测 |

### 1.4 建筑

| 状态 | 时长 | 备注 |
|---|---|---|
| Construction | 建造时长 | **从下往上"生长"**——用 shader 的 `_ClipHeight` 参数裁剪，省动画 |
| Normal | 循环 | 电厂有轻微排烟，兵营有旗子摆动 |
| Producing | 循环 | 生产时灯光闪烁 / 门开合，让玩家知道在干活 |
| Damaged | 循环 | HP < 40% 时切换：冒烟 + 火花间歇 |
| Destroyed | 2s | 分段坍塌 → 保留废墟（废墟可作掩体，见设计案 §5.2） |

## 2. 移动端动画性能策略

### 2.1 骨骼预算

| 类型 | 骨骼数 | 说明 |
|---|---|---|
| 步兵 | **≤ 24** | 根+脊柱3+头+双臂各5+双腿各4 |
| 载具 | **≤ 8** | 车身 1 + 履带 2 + 炮塔独立 1 + 炮管 1 |
| 飞行器 | **≤ 6** | 机身 + 螺旋桨（用旋转不用骨骼）+ 起落架 |
| 建筑 | **0（无骨骼）** | 全部用 shader 动画 + 部件位移 |

> **建筑不用骨骼**是关键：一局游戏最多 20 栋建筑，每栋 20 骨骼 = 400 骨骼的动画计算，纯浪费。用 shader 与 transform 位移即可。

### 2.2 动画 LOD

| 距离状态 | 播放策略 |
|---|---|
| 近（屏幕内，zoom 近） | 全状态机，含 HitReact / 细节动画 |
| 中（屏幕内，zoom 远） | 只播 Idle / Move / Attack / Death 四态 |
| 远（屏幕外） | **完全停止动画更新**，只更新逻辑 |
| 混战中超过 60 单位 | 关闭 HitReact，只留 Death |

**实现**：`AnimationLODManager` 每 0.5s 评估一次每个单位的距离档位，切换 `Animator.cullingMode` 与更新频率。

### 2.3 GPU Skinning

- 开启 **GPU Skinning（Compute Shader）**，把蒙皮计算从 CPU 挪到 GPU。
- 配合 **GPU Instancing**：同兵种 20 个单位共享一次蒙皮计算。
- 低端机降级：关闭 GPU Skinning，改用 **顶点动画贴图（VAT）**——把动画烘到贴图，1 个 Draw Call 画 100 个动画单位，代价是内存 +4MB/兵种。

### 2.4 动画压缩

| 项 | 设置 |
|---|---|
| 压缩方式 | **Optimal**（不是 Keyframe Reduction） |
| 旋转精度 | 0.5 度 |
| 位置精度 | 0.5cm |
| 缩放 | **关闭**（本项目所有动画不需要缩放） |
| 采样率 | 15fps（动画数据，非渲染帧率） |

15fps 采样在移动端小屏幕上肉眼不可辨，但数据量减半。

## 3. 触屏操作动画反馈

| 交互 | 动画表现 | 时长 | 优先级 |
|---|---|---|---|
| **点击选中** | 单位轻微"抬头"或"端起武器" | 0.2s | ★★★★ |
| **框选完成** | 全体单位同时朝镜头方向微转（像在等候命令） | 0.3s | ★★★★★ 反馈感最强 |
| **移动命令** | 单位先转向目标方向，0.1s 后才起步 | 0.1s + 起 | ★★★★ |
| **攻击命令** | 炮塔/身体快速转向目标，武器上抬 | 0.3s | ★★★★★ |
| **建筑放置** | 放置瞬间有"降落 + 冲击波"动画 | 0.4s | ★★★★ |
| **生产完成** | 单位从建筑门口"走 / 开出来"，不是凭空出现 | 0.6s | ★★★★★ 极重要 |
| **编队切换** | 编队按钮按下时对应单位集体闪光一次 | 0.15s | ★★★ |

**"生产完成从门里开出来"** 是 RTS 的仪式感核心。凭空刷出来的兵会让玩家觉得自己在点外卖，而不是在指挥军队。

## 4. 战斗动画反馈

### 4.1 攻击节奏（打击感来源）

| 武器 | 前摇 | 开火 | 后摇 | 总时长 | 说明 |
|---|---|---|---|---|---|
| 步枪 | 0.1s | 1帧闪光 | 0.15s | 0.25s | 单发，节奏紧凑 |
| 机枪 | 0.15s | 持续 0.6s | 0.2s | 0.95s | 连发，枪口抖动 |
| 火炮 | 0.4s | 1帧 | 后坐 0.5s | 0.9s | 前摇长，打击重 |
| 激光 | 0.2s | 持续 0.4s | 0.1s | 0.7s | 充能→瞬发→消散 |
| 特斯拉 | 0.3s | 持续 0.5s | 0.2s | 1.0s | 电弧闪烁不规则 |

**前摇必须存在**：没有前摇的攻击看起来像"数值凭空结算"，没有重量感。0.1–0.4s 的前摇是打击感的全部来源。

### 4.2 死亡动画（按性能选）

| 方案 | 性能 | 视觉 | 采用 |
|---|---|---|---|
| 溶解（Dissolve Shader） | 极低（1 个 shader 参数） | 一般 | ✅ **步兵主用** |
| 倒地（Ragdoll） | **极高，移动端禁用** | 好 | ❌ |
| 倒地（预烘焙） | 低 | 好 | ✅ 步兵备选 |
| 爆炸（换残骸 mesh） | 低 | 好 | ✅ **载具主用** |
| 下沉 + 碎片 | 中 | 好 | ✅ 建筑用 |

**禁止 Ragdoll**：物理布娃娃在移动端是性能杀手，10 个单位同时死亡就掉帧。用预烘焙倒地动画完全够用。

### 4.3 受击反馈

- **金属受击**：模型材质闪白 1 帧 + 金属火花粒子（3 颗）。
- **步兵受击**：**不播 HitReact**（会打断移动动画），改为血条上方红字飘伤害数字。
- **重击（火炮/爆炸）**：屏幕轻微震动（0.05s，幅度 2px），**只对玩家视线中心区域**生效，避免全局震动导致晕。

## 5. 阶段 2 最小清单

| 项目 | 阶段2 用什么代替 | 阶段3 换成什么 |
|---|---|---|
| 步兵动画 | 一个 Idle 呼吸 + 一个平移 | 完整 7 态状态机 |
| 载具动画 | 车身整体平移 + 炮塔转向 | 完整状态机 + 履带 UV 滚动 |
| 炮塔转向 | transform 旋转 | 独立动画层混合 |
| 攻击 | 无前摇，直接扣血 | 完整前摇/后摇节奏 |
| 死亡 | 直接 SetActive(false) | 溶解 / 爆炸残骸 |
| 建筑建造 | 进度条 + 直接出现 | 从下往上生长 shader |
| 生产完成 | 直接出现在建筑旁 | 从门口驶出 |

**验收点（阶段2 必须达标）**：
1. 单位移动时**没有滑步**（步频与速度匹配）。
2. 攻击有**可感知的前摇**，玩家能看出"它要打了"。
3. 炮塔能独立转向（不是整个车转身）。
