## 2. 遭遇战选择流程

```
遭遇战 → 选择背景 → 选择阵营 → 选择难度 → 选择地图 → 开始
```

### 2.1 背景选择

| 背景 | 状态 | 说明 |
|---|---|---|
| 二战 | 免费 | 默认解锁 |
| 冷兵器 | ¥6 / 礼包 | 需内购 |
| 一战 | ¥6 / 礼包 | 需内购 |
| 二战后局部 | ¥6 / 礼包 | 需内购 |
| 现代战争 | ¥12 / 礼包 | 需内购 |

### 2.2 阵营选择

根据选的背景显示对应两个阵营卡片，含阵营名称、特色描述、修正系数。

### 2.3 难度选择

简单 / 普通 / 困难（三档，显示 AI 行为差异说明）

### 2.4 地图选择

显示当前背景的 6 张地图缩略图，标注类型(1v1/2v2/4人)和特点。
