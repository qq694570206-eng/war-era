## 1. 音效分类与清单

### 1.1 单位语音（红警的灵魂）

| 触发 | 内容 | 赤卫军口音 | 铁盟口音 | 备注 |
|---|---|---|---|---|
| 选中 | "报告" / "等候命令" | 粗犷俄式中文 | 沉稳美式中文 | 每单位 2–3 句轮换 |
| 移动 | "明白" / "出发" | "收到，前进！" | "移动中。" | |
| 攻击 | "开火！" / "消灭他们" | "为祖国开火！" | "锁定目标。" | |
| 死亡 | 短促惨叫 | — | — | 每单位 1 句 |
| 生产完成 | "单位就绪" | 女声播报"赤卫军就绪" | 女声播报"铁盟就绪" | 阵营统一，不分单位 |
| 建筑完成 | "建筑完成" | 同上风格 | 同上风格 | |
| 超武就绪 | "终极武器就绪" | 庄严男声 | 冷静女声 | 必须有压迫感 |

**关键**：**每单位语音不超过 3 句轮换**。红警的经典感来自"听烦了但还在听"——不是多样性，是重复中的亲切。移动端尤其如此，玩家注意力在战场不在耳朵。

### 1.2 武器音效

| 武器 | 音效描述 | 时长 | 同时上限 |
|---|---|---|---|
| 步枪 | 清脆单发"啪" | 0.15s | 20 |
| 机枪 | 连续"嗒嗒嗒" | 持续 | 8 |
| 火炮 | 低沉"轰"+ 远景回响 | 0.6s | 6 |
| 导弹 | "嗖"发射 + "轰"命中 | 1.0s | 4 |
| 激光 | 电子"嗡——吱" | 0.4s | 4 |
| 特斯拉 | "滋啦——噼啪"不规则电流声 | 0.5s | 3 |

### 1.3 爆炸音效

| 类型 | 音效 | 同时上限 |
|---|---|---|
| 小爆炸（手雷） | 中频"嘭" | 8 |
| 大爆炸（炮弹） | 低频"轰隆" + 碎片声 | 4 |
| 建筑爆炸 | 多层：低频爆 + 金属撕裂 + 持续燃烧 | 2 |
| 核弹 | **见 §3.2 超武音效序列** | 1 |

### 1.4 建筑音效

| 触发 | 音效 |
|---|---|
| 建造中 | 施工锤击声循环 |
| 建造完成 | 金属"咔"锁扣声 |
| 生产中 | 工厂机械运转循环 |
| 被攻击 | 金属撞击 + 警报蜂鸣 |
| 被摧毁 | 坍塌轰鸣 + 火焰燃烧 |

### 1.5 UI 音效

| 触发 | 音效 |
|---|---|
| 按钮点击 | 清脆"嘀" |
| 建造面板展开 | 机械"咔嚓" |
| 选中单位 | 轻"嘟" |
| 框选完成 | 短促"唰" |
| 命令下达（移动） | 轻"嗒" |
| 命令下达（攻击） | 轻"叮"（比移动高半音） |
| 错误操作（不可建/没钱） | 低沉"嗯嗯"（否定感） |
| 超武就绪 | 庄严警报 3 声 |
| 基地被攻击 | 急促警报循环，直到威胁消除 |

### 1.6 环境音

| 场景 | 音效 |
|---|---|
| 战场背景 | 远处炮声（每 8–15s 一次随机）+ 风声底噪 |
| 基地内部 | 引擎嗡鸣（电厂）+ 机械运转（车厂） |
| 战斗密集区 | 枪声底噪 + 喊叫（远景，低音量） |

## 2. 移动端音频性能策略

### 2.1 声道预算

| 档位 | 同时播放声道 | 说明 |
|---|---|---|
| 低端 | **16** | Unity 默认 32，主动降到 16 |
| 中端 | 24 | |
| 高端 | 32 | 不要超过 32，移动端硬件限制 |

### 2.2 音频压缩格式

| 类型 | 格式 | 码率 | 说明 |
|---|---|---|---|
| 短音效（枪/爆炸/UI） | **ADPCM** | — | 解码极快，适合频繁播放 |
| 长音效（环境/建筑循环） | **Vorbis (OGG)** | 96kbps | 压缩率高 |
| 音乐 | **Vorbis (OGG)** | 128kbps | |
| 语音 | **Vorbis (OGG)** | 64kbps mono | 人声不需要立体声 |

**禁止**：用 WAV 或 PCM—— uncompressed 音频在移动端会吃光内存。

**总音频内存预算**：≤ 60MB。

### 2.3 音频池化与复用

| 池 | 数量 | 说明 |
|---|---|---|
| AudioSource | **32**（=声道上限） | 开局预创建，战斗中不新建 |
| 枪声音效实例 | 8 | 轮换使用，避免同一枪声叠放爆音 |
| 爆炸音效实例 | 6 | |
| UI 音效实例 | 4 | |
| 语音实例 | 4 | 同一单位语音不叠放 |

**铁律**：**战斗中零 `Instantiate`**，所有 AudioSource 在 Loading 时预创建并池化。

### 2.4 大量单位同时开火——防爆音策略

这是移动端 RTS 音频的最大难题。100 个单位同时开枪 = 100 个枪声 = 爆音 + 硬件过载。

| 策略 | 做法 | 效果 |
|---|---|---|
| **距离衰减** | 超过摄像机视野 30m 的单位开火不播音 | 砍掉 60% 远处音效 |
| **合并播放** | 同类武器在 0.1s 内的多次开火**只播一次**，音量 +3dB | 20 挺机枪齐射听起来像"一挺但更响" |
| **随机变调** | 每次播放随机 ±5% 音调 | 避免完全相同的音效叠放听感机械 |
| **优先级** | UI > 超武 > 建筑 > 大爆炸 > 玩家单位 > 远处单位 | 超出声道时低优先级的被截断 |
| **3D 空间化降级** | 超过 20m 的音效切回 2D 单声道 + 音量衰减 | 3D Spatialization 在移动端贵，远处不值得 |

**效果目标**：100 单位混战时，玩家听到的不是"100 声枪响"，而是"一片战场的嘈杂"——这是正确的设计。

### 2.5 3D 空间音频 vs 2D

| 场景 | 用 3D 还是 2D | 理由 |
|---|---|---|
| 枪声/爆炸（近） | **3D** | 方向感是战场的核心信息 |
| 枪声/爆炸（远，>20m） | **2D + 衰减** | 省性能，远处方向感不重要 |
| UI 音效 | **2D** | UI 没有空间位置 |
| 单位语音 | **2D** | 语音要听得清，不能被空间化搞糊 |
| 超武音效 | **2D** | 全屏事件，不定位 |
| 环境音 | **2D** | 背景底噪 |
| 音乐 | **2D** | — |

**原则**：**只有近处战斗音效用 3D，其余全部 2D**。移动端 3D Spatialization 的 CPU 开销不可忽视。

## 3. 红警经典音频还原

### 3.1 单位语音风格

| 阵营 | 风格 | 参考感觉 |
|---|---|---|
| 赤卫军 | 粗犷、直接、带俄式口音的中文 | "收到，前进！" 不是 "收到，开始移动。" |
| 铁盟 | 沉稳、专业、美式军事口吻 | "锁定目标。" 不是 "好的，我去打他。" |

**配音指导**：
- 语速偏快（移动端节奏比红警快）。
- 每句 ≤ 1.5 秒。
- 语气要有"军令如山"的确定感，不要犹豫。
- 女声播报（生产完成/建筑完成/超武）用**冷静、机械感**的声线，与单位男声形成对比。

### 3.2 超武音效序列

| 阶段 | 时长 | 音效 |
|---|---|---|
| ① 超武就绪提示 | 2.0s | 庄严警报 3 声 + 女声"终极武器就绪" |
| ② 发射 | 1.5s | 低频上升嗡鸣（充能感） |
| ③ 命中瞬间 | 0.5s | **全静音 0.2s + 爆发性低频轰鸣** |
| ④ 蘑菇云上升 | 2.0s | 持续低频轰鸣 + 高频风声 |
| ⑤ 辐射残留 | 5.0s | 间歇性电流声 + 低频底噪 |

**"命中瞬间全静音 0.2s"** 是核弹音效的灵魂——先让玩家"听不到"，再用轰鸣砸回来，对比产生冲击力。这一条比加多少低频都有效。

### 3.3 警报与提示音

| 事件 | 音效 | 说明 |
|---|---|---|
| 基地被攻击 | 急促"嘀嘀嘀"循环 | 直到威胁消除才停 |
| 电力不足 | 低沉"嗡——" 一次 | 建造被阻断时触发 |
| 矿石不足 | 轻"叮"否定音 | 尝试建造/生产但钱不够 |
| 单位升级 | 上扬"叮——" | 正向反馈 |
| 控制点被占 | 中频警报 2 声 | 战术提醒 |

### 3.4 战场音乐风格

| 阵营 | 风格 | 参考 |
|---|---|---|
| 赤卫军 | **重型管弦 + 工业打击乐** | 红警 2 苏联军歌的现代版 |
| 铁盟 | **电子合成 + 军鼓行进** | 红警 2 盟军主题的电子化 |
| 中立菜单 | 悬疑弦乐底 + 远处炮声 | 开局氛围 |

**音乐结构**：
- 每阵营 1 首主题（3 分钟循环）。
- 战斗激烈时**自动切换到变奏版**（节奏加快 + 加鼓）。
- 超武触发时**音乐 ducking 降低 6dB**，让超武音效占主导。

## 4. 触屏操作音频反馈

| 交互 | 音效 | 说明 |
|---|---|---|
| 选中单位 | 轻"嘟" | 每次选中都播，确认操作生效 |
| 框选完成 | 短"唰" | 只在框选结束时播一次 |
| 移动命令 | 轻"嗒" | 比选中音低半音，区分"命令"与"选择" |
| 攻击命令 | 轻"叮" | 比移动音高半音，传达"更重要的命令" |
| 建筑放置 | 机械"咔" + 轻"嗡"启动 | 放置确认 + 建造开始的衔接 |
| 错误操作 | 低沉"嗯嗯" | 否定感强，但不刺耳 |
| 编队切换 | 轻"咔" | 切换编队时的确认 |
| 双击编队（跳转镜头） | "嗖" | 镜头移动的伴随音 |

**原则**：**每个触屏操作必须有音效反馈**。触屏没有物理按键的触感，音效是"操作生效"的唯一即时确认。这一条在移动端比 PC 更重要。

## 5. 阶段 2 最小清单

| 项目 | 阶段2 用什么代替 | 阶段3 换成什么 |
|---|---|---|
| 单位语音 | 静音 | 完整语音（每单位 3 句） |
| 枪声 | 1 个通用"啪" | 分类枪声 |
| 爆炸 | 1 个通用"轰" | 分类爆炸 |
| UI 音效 | 1 个通用"嘀" | 分类 UI 音效 |
| 建筑 | 静音 | 施工/完成/被攻击音效 |
| 超武 | 通用爆炸音 | 完整 5 阶段序列 |
| 警报 | 通用"嘀嘀" | 分类警报 |
| 环境 | 静音 | 战场背景音 |
| 音乐 | 静音或 1 首循环 | 阵营主题 + 战斗变奏 |

**验收点（阶段2 必须达标）**：
1. **每个操作有音效反馈**（哪怕是同一个"嘀"）。
2. **有至少一种爆炸音**，让玩家能听见"有东西被打了"。
3. **不会爆音**（10 个单位同时开火时音量不刺耳）。
