# 三、本地化方案

## 1. 支持语言

| 语言 | 代码 | 优先级 |
|---|---|---|
| 简体中文 | zh-CN | P0(首发) |
| English | en | P1(首版补丁) |
| 繁体中文 | zh-TW | P2 |
| 日语 | ja | P3 |

## 2. 文本表结构

```csv
key,zh-CN,en,zh-TW,ja
ui.ore,矿石,Ore,礦石,鉱石
ui.power,电力,Power,電力,電力
ui.tech,科技点,Tech,科技點,テック
unit.rifleman,步枪兵,Rifleman,步槍兵,ライフル兵
unit.tank,中型坦克,Medium Tank,中型坦克,中戦車
building.hq,指挥中心,Headquarters,指揮中心,司令部
...
```

## 3. 实现方案

- 用 Unity Localization Package 或简单的 CSV → Dictionary
- 启动时读取 `Resources/Localization/strings.csv`
- 所有 UI 文本通过 `L.Get("key")` 获取
- 语音暂不做多语言（只中文）

# 四、存档系统

## 1. 存档类型

| 类型 | 存储方式 | 容量 | 说明 |
|---|---|---|---|
| 遭遇战存档 | PlayerPrefs JSON | 1个(免费)/5个(内购) | 保存当前战斗状态 |
| 战役进度 | PlayerPrefs | 1个 | 通关记录+三星 |
| 设置 | PlayerPrefs | 1个 | 画面/音效/操作设置 |
| 内购状态 | PlayerPrefs + 云同步 | — | 已购商品列表 |

## 2. 遭遇战存档数据结构

```json
{
  "mapId": "plain",
  "themeId": "ww2",
  "faction": "allies",
  "difficulty": "normal",
  "gameTime": 342.5,
  "ore": 1250,
  "techPoints": 5,
  "techLevel": 2,
  "purchasedTechs": ["t2","armor"],
  "units": [
    {"type":"rifleman","x":250,"y":800,"hp":80,"targetX":null},
    {"type":"tank","x":300,"y":850,"hp":500,"targetX":600}
  ],
  "buildings": [
    {"type":"hq","x":200,"y":1200,"hp":2400,"buildProgress":1},
    {"type":"barracks","x":280,"y":1140,"hp":600,"buildProgress":1}
  ],
  "enemyUnits": [...],
  "enemyBuildings": [...],
  "exploredGrid": "base64编码的迷雾数据"
}
```

## 3. 存档时机

- 玩家手动存档（暂停→存档）
- 切后台时自动存档
- 每 30 秒自动存档(防崩溃)

# 五、教程引导系统

## 1. 引导流程

首次进入遭遇战时自动触发：

| 步 | 引导内容 | 触发条件 |
|---|---|---|
| 1 | "欢迎来到钢铁防线" | 首次进入 |
| 2 | "点击采矿车选中它" | HQ 旁有采矿车 |
| 3 | "点击金色矿点指派采集" | 选中采矿车后 |
| 4 | "矿石在增长！现在建造电厂" | 矿石>300 |
| 5 | "点击底部建造面板的电厂" | — |
| 6 | "点击地图放置建筑(绿框可建)" | 选了建筑 |
| 7 | "建造兵营，然后生产步兵" | 电厂建成 |
| 8 | "框选单位(长按拖动)" | 步兵产出 |
| 9 | "选中单位后点击地面移动" | — |
| 10 | "点击敌人攻击" | 出现敌方 |
| 11 | "建造车厂出坦克" | 矿石>800 |
| 12 | "长按编队按钮编入单位" | 有 3+ 单位 |
| 13 | "建造雷达站解锁超武" | T2 科技 |
| 14 | "教程完成！开始自由对战" | — |

## 2. 实现方案

- `TutorialManager.cs` 监听游戏事件，按步骤触发引导
- 引导为半透明手指动画 + 文字气泡
- 可在设置中关闭"教程引导"
- 完成后 `PlayerPrefs.SetInt("tutorial_done", 1)`

# 八、数据分析/埋点

## 1. 关键指标

| 指标 | 说明 | 用途 |
|---|---|---|
| DAU | 日活用户 | 基础 |
| 次日留存 | 次日回来玩的比例 | 评估新手体验 |
| 7日留存 | 7日留存 | 评估长期吸引力 |
| 付费率 | 付费用户/总用户 | 变现评估 |
| ARPPU | 每付费用户平均收入 | 变现评估 |
| 平均对局时长 | 每场战斗平均时间 | 节奏调优 |
| 胜率 | 玩家胜率(分难度) | 难度调优 |
| 内购转化率 | 看到商品→购买的比例 | 商店优化 |

## 2. 埋点事件

| 事件名 | 触发时机 | 参数 |
|---|---|---|
| game_start | 进入战斗 | theme/faction/difficulty/map |
| game_end | 战斗结束 | result(win/lose)/duration/units_lost |
| build_place | 放置建筑 | building_type/cost |
| unit_produce | 生产单位 | unit_type/cost |
| tech_upgrade | 科技升级 | upgrade_id |
| superweapon_fire | 超武发射 | target_x/target_y |
| squad_assign | 编入编队 | slot |
| ad_watch | 看广告 | ad_type/reward |
| iap_purchase | 内购 | product_id/price |
| level_complete | 战役关卡完成 | level/stars/time |
| tutorial_step | 教程步骤完成 | step |
| session_start | 打开游戏 | — |
| session_end | 关闭游戏 | session_duration |

## 3. 实现方案

- 用 **Unity Analytics**（官方，零额外 SDK）
- 或 **Firebase Analytics**（Google，更详细）
- 建议：Unity Analytics 为主（集成简单）
