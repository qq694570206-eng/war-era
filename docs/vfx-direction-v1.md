## 2. 移动端特效性能策略

### 2.1 粒子预算

| 档位 | 单个特效粒子数 | 同屏粒子总数 | 说明 |
|---|---|---|---|
| 低端 | ≤ 15 | ≤ 200 | 用面片粒子，不用 mesh 粒子 |
| 中端 | ≤ 30 | ≤ 500 | 标准 |
| 高端 | ≤ 50 | ≤ 800 | 大爆炸允许突破单次 |

**铁律**：**同屏粒子超过预算时，优先削减最老的特效**（不是最远的）。用对象池 + LRU 淘汰。

### 2.2 特效 LOD

| 距离 | 表现 |
|---|---|
| 近 | 完整粒子 + 光照 + 烟雾 |
| 中 | 粒子数 ×0.5，去掉烟雾，保留爆点 |
| 远 | 粒子数 ×0.2，只剩一个亮闪 |
| 屏幕外 | **完全停止**，只留逻辑伤害结算 |

**关键**：爆炸特效在屏幕外时**只播音效，不播特效**——这是移动端 RTS 最省的一条。

### 2.3 特效池化

| 池类型 | 预实例数量 | 说明 |
|---|---|---|
| 枪口焰 | 30 | 复用最频繁 |
| 小爆炸 | 20 | |
| 大爆炸 | 8 | |
| 特斯拉电弧 | 6 | |
| 激光线段 | 10 | 用 LineRenderer，不用粒子 |
| 烟雾柱 | 15 | |
| UI 环 | 50 | 选中/移动/攻击指示 |
| 伤害飘字 | 80 | |

**总池容量**：约 220 个特效实例，内存约 8MB。

### 2.4 贴图图集

| 图集 | 尺寸 | 内容 |
|---|---|---|
| 特效主图集 | 1024×1024 | 所有粒子贴图（火花、烟雾、爆点、光束） |
| 特效 UI 图集 | 512×512 | 选中环、准星、框选框 |

**禁止**：每个特效独占一张贴图。所有特效贴图合到一张图集里，1 个材质搞定全部特效。

### 2.5 超武特效特殊处理

超武特效是"一局一次"的仪式，可以突破预算，但不能跨帧卡顿。

**策略**：超武特效**分帧预渲染**——在超武就绪倒计时的最后 5 秒，把粒子状态提前预热到"即将爆发"的临界状态，触发时只需 `Play()` 不需要初始化，避免触发瞬间的主线程尖峰。

## 3. 红警经典特效还原

### 3.1 特斯拉电弧

| 属性 | 设计 |
|---|---|
| 视觉 | 从发射单位到目标之间，蓝紫色锯齿状线段，2–3 条分支 |
| 实现 | 用 **LineRenderer + 动态顶点抖动**，每帧重新生成 5–8 个中间点的随机偏移 |
| 时长 | 0.3s 闪烁 + 0.2s 消散 |
| 声音 | 见音频方案 §3 |
| 性能 | LineRenderer 比 Particle System 便宜 5 倍，适合频繁出现 |

**关键**：电弧的"锯齿"不是贴图，是**程序化生成的折线**——每个中间顶点每帧随机抖动 ±0.3m，这就是红警特斯拉的视觉灵魂。

### 3.2 核弹爆炸序列

| 阶段 | 时长 | 视觉 | 性能策略 |
|---|---|---|---|
| ① 投射 | 1.5s | 导弹从天而降，带尾烟 | 单一粒子拖尾 |
| ② 落地闪光 | 0.1s | **全屏白闪**（UI 层覆盖，不是 3D 特效） | 用 UI Image，不耗 GPU |
| ③ 蘑菇云上升 | 2.0s | 橙红色球体膨胀 + 向上拉伸为蘑菇形 | 预制 morphing mesh |
| ④ 冲击波 | 0.5s | 地面圆形扩散环（贴花，非粒子） | 1 个地面贴花扩散 |
| ⑤ 持续辐射 | 5.0s | 地面残留紫色辐射区域 + 间歇火花 | 1 个区域贴花 + 5 颗粒子 |
| ⑥ 烟柱 | 10.0s | 黑色烟柱缓慢消散 | 1 个粒子系统缓慢衰减 |

**总粒子数**：峰值约 80 颗（在高端机预算内）。关键是**蘑菇云用 mesh 变形而非粒子**，省 90% 性能。

### 3.3 光棱塔折射光束

| 属性 | 设计 |
|---|---|
| 视觉 | 蓝色光束从塔顶发射，可在友军光棱塔之间弹射折射 |
| 实现 | LineRenderer 链式绘制，每次折射在中间塔位置加一个节点 |
| 时长 | 0.3s 显现 + 0.2s 消散 |

### 3.4 建筑被毁碎片与烟柱

| 属性 | 设计 |
|---|---|
| 碎片 | 3–5 块刚体碎片飞出，2s 后消失（不用持久刚体，性能杀手） |
| 烟柱 | 黑色粒子柱，持续 10s 渐淡 |
| 残骸 | 切换到"废墟 mesh"（低面数），保留至本局结束，可作掩体 |

## 4. 触屏交互特效

| 交互 | 特效 | 性能 |
|---|---|---|
| 框选 | 半透明矩形 UI，**不做粒子** | 极低 |
| 建筑放置预览 | 绿框/红框 UI + 半透明模型 | 低 |
| 移动指示 | 地面贴花圆环扩散 | 低（1 个贴花） |
| 攻击指示 | 地面红色十字贴花 | 低 |
| 选中 | 地面阵营色环（不是粒子，是贴花 mesh） | 低 |
| 编队切换 | 编队按钮 UI 闪光 | 极低 |

**原则**：**UI 交互特效全部不用粒子**。用贴花、UI 元素、shader 闪光即可。粒子只用于战场上的武器与爆炸。

## 5. 阶段 2 最小清单

| 项目 | 阶段2 用什么代替 | 阶段3 换成什么 |
|---|---|---|
| 枪口焰 | 不做，直接扣血 | 分类枪口焰 |
| 爆炸 | 1 个通用粒子爆点 | 分类爆炸（火炮/手雷/导弹） |
| 特斯拉 | 不做（用通用爆点） | LineRenderer 电弧 |
| 激光 | 不做（用通用爆点） | LineRenderer 光束 |
| 核弹 | 全屏白闪 + 1 个爆点 | 完整 6 阶段序列 |
| 选中环 | Unity 内置 Projector | 贴花 mesh 环 |
| 移动指示 | 不做 | 贴花扩散环 |
| 建筑放置 | 绿/红框 UI | 绿/红框 + 半透明模型 |
| 伤害飘字 | 不做 | UI 飘字 |

**验收点（阶段2 必须达标）**：
1. 有**至少一种**爆炸特效，让玩家能看出"有东西被打了"。
2. 选中单位时**有视觉反馈**（哪怕是 Projector 投影一个圆）。
3. 建筑放置**有绿框红框**，玩家不会建到不知道能不能建的地方。
